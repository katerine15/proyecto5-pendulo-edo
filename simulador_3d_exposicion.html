¿Cuándo vale la aproximación lineal?

1. El punto a mano

Primero la matemática: resolvemos a mano el modelo lineal, deducimos su período y justificamos la aproximación con Taylor. Después el programa comprueba esta solución.

Enunciado. «Resolver la ecuación lineal con θ(0) = θ₀, θ'(0) = 0, y deducir el período T₀ = 2π√(L/g). Observar que T₀ no depende de la amplitud. Justificar la aproximación con el polinomio de Taylor de sen θ y estimar el error relativo en θ₀ = 10° y en θ₀ = 90°»

El procedimiento en resumen

  1. Modelo. θ'' + (g/L)·sen θ = 0: θ'' es la aceleración angular y (g/L)·sen θ el término que lo devuelve a la vertical, con L = 1 m y g = 9.81 m/s².
  2. Aproximación. sen θ ≈ θ − θ³/6 + θ⁵/120; para ángulos pequeños se conserva solo θ. El error es de 0.51 % a 10° y de 57.08 % a 90°.
  3. Ecuación característica. De θ'' + (g/L)θ = 0 sale r² + g/L = 0, luego r = ± i√(g/L), con ω = √(g/L).
  4. Solución general. θ(t) = C₁·cos(ωt) + C₂·sen(ωt).
  5. Condiciones iniciales. θ(0) = θ₀ ⇒ C₁ = θ₀; θ'(0) = 0 ⇒ C₂ = 0. Por tanto θ(t) = θ₀·cos(ωt).
  6. Período. T₀ = 2π/ω = 2π√(L/g) ≈ 2.0061 s. θ₀ no aparece en la fórmula: el modelo lineal es isócrono.
θ'' + (g/L)·sen θ = 0 → (sen θ ≈ θ) → θ'' + (g/L)·θ = 0 → θ(t) = θ₀·cos(ωt), ω = √(g/L)

01Ecuación lineal y condiciones iniciales
La ecuación del péndulo con sen θ ≈ θ. Arranca en θ₀ y quieto.
\theta''+\frac{g}{L}\,\theta=0,\qquad \theta(0)=\theta_0,\quad \theta'(0)=0
import math                          # sen, cos, raíz, π
import numpy as np                   # para np.roots

# gravedad (m/s²) y largo (m)
g, L = 9.81, 1.0
# θ(0) = θ0, en radianes
theta0 = math.radians(10)
# θ'(0) = 0: se suelta quieto
dtheta0 = 0.0
02Se propone θ = eʳᵗ y se deriva
Probamos una exponencial y sacamos sus dos derivadas.
\theta=e^{rt},\qquad \theta'=r\,e^{rt},\qquad \theta''=r^{2}e^{rt}
# se prueba θ = e^(rt) y se deriva dos veces
# θ   = e^(rt)
theta_e   = lambda r, t: math.exp(r*t)
# θ'  = r·e^(rt)
dtheta_e  = lambda r, t: r * math.exp(r*t)
# θ'' = r²·e^(rt)
d2theta_e = lambda r, t: r**2 * math.exp(r*t)
03Se reemplaza y se factoriza eʳᵗ
Metemos θ y θ'' en la ecuación. eʳᵗ nunca es 0, así que queda r² + g/L = 0.
\begin{aligned} r^{2}e^{rt}+\frac{g}{L}\,e^{rt}&=0\\ e^{rt}\left(r^{2}+\frac{g}{L}\right)&=0\\ e^{rt}\neq 0\;\Rightarrow\; r^{2}+\frac{g}{L}&=0 \end{aligned}
# r²·e^(rt) + (g/L)·e^(rt) = e^(rt)·(r² + g/L) = 0
# e^(rt) nunca es 0, así que queda r² + 0·r + g/L = 0
# coeficientes de r², r y 1
caracteristica = [1, 0, g / L]
04Se despeja r
Sale la raíz de un número negativo: por eso aparece i.
\begin{aligned} r^{2}&=-\frac{g}{L}\\ \sqrt{r^{2}}&=\pm\sqrt{-\frac{g}{L}}\\ r&=\pm\sqrt{-1}\cdot\sqrt{\frac{g}{L}}\qquad\leftarrow\ i=\sqrt{-1}\ \text{(unidad imaginaria)}\\ r&=\pm i\sqrt{\frac{g}{L}}=\pm i\omega,\qquad \omega=\sqrt{\frac{g}{L}}\ \text{(frecuencia natural)} \end{aligned}
# raíces del polinomio
r1, r2 = np.roots(caracteristica)
omega = math.sqrt(g / L)             # ω = √(g/L)
print(f"r = {abs(r1.real):.0f} ± {abs(r1.imag):.4f}i")
# → r = 0 ± 3.1321i
print(round(omega, 4))
# → 3.1321
05Raíces complejas → solución general
Raíces a ± bi con a = 0: la solución es cosenos y senos.
\begin{aligned} r&=a\pm bi=0\pm i\omega\qquad(a=0,\;b=\omega)\\ \theta(t)&=e^{0\cdot t}\left(C_1\cos(\omega t)+C_2\sen(\omega t)\right)\\ e^{0}=1\;\Rightarrow\;\theta(t)&=C_1\cos(\omega t)+C_2\sen(\omega t) \end{aligned}
# r = a ± bi → a = 0, b = ω
a, b = r1.real, abs(r1.imag)
print(math.exp(a * 1.0))
# → 1.0

# e^(at)·(C1·cos bt + C2·sen bt)
def theta_general(t, C1, C2):
    return math.exp(a*t) * (C1*math.cos(b*t)
                            + C2*math.sin(b*t))
06Primera condición: θ(0) = θ₀ (ángulo inicial o amplitud)
En t = 0: cos 0 = 1 y sen 0 = 0, así sale C₁ = θ₀.
\begin{aligned} \theta(0)&=C_1\cos(\omega\cdot 0)+C_2\sen(\omega\cdot 0)=\theta_0\\ &=C_1\cos(0)+C_2\sen(0)=\theta_0\\ &=C_1(1)+C_2(0)=\theta_0\\ &=C_1+0=\theta_0\;\Rightarrow\;C_1=\theta_0 \end{aligned}
# θ(0) = C1·cos(0) + C2·sen(0) = C1·1 + C2·0
C1 = theta0                          # entonces C1 = θ0
07Se deriva θ(t) para obtener velocidad angular
Derivamos para tener la velocidad θ'.
\theta'(t)=-C_1\,\omega\sen(\omega t)+C_2\,\omega\cos(\omega t)
def dtheta_general(t, C1, C2):       # derivada de θ(t)
    # (cos ωt)' = −ω·sen ωt   y   (sen ωt)' = ω·cos ωt
    return (-C1*omega*math.sin(omega*t)
            + C2*omega*math.cos(omega*t))
08Segunda condición: θ'(0) = 0 (se suelta desde el reposo)
Al soltarlo la velocidad es 0: de ahí sale C₂ = 0.
\begin{aligned} \theta'(0)&=-C_1\,\omega\sen(\omega\cdot 0)+C_2\,\omega\cos(\omega\cdot 0)=0\\ &=-C_1\,\omega\sen(0)+C_2\,\omega\cos(0)=0\\ &=-C_1\,\omega(0)+C_2\,\omega(1)=0\\ &=0+C_2\,\omega=0\\ C_2\,\omega&=0\;\Rightarrow\;C_2=\frac{0}{\omega}=0 \end{aligned}
# θ'(0) = −C1·ω·sen(0) + C2·ω·cos(0) = C2·ω = 0
C2 = dtheta0 / omega                 # C2·ω = 0 → C2 = 0
print(dtheta_general(0, C1, C2))
# → 0.0
09Se sustituye C₁ y C₂ · solución particular
Con C₁ y C₂ el péndulo lineal queda como un coseno.
\begin{aligned} \theta(t)&=\theta_0\cos(\omega t)+0\cdot\sen(\omega t)\\ \Rightarrow\;\theta(t)&=\theta_0\cos(\omega t)\\ \omega=\sqrt{\frac{g}{L}}\;\Rightarrow\;\theta(t)&=\boxed{\theta_0\cos\!\left(\sqrt{\frac{g}{L}}\;t\right)} \end{aligned}
# solución particular
def theta(t):
    # ω = √(g/L) ya reemplazado
    return theta0 * math.cos(math.sqrt(g / L) * t)

# isclose compara sin errores de redondeo
print(math.isclose(theta(1.0), theta_general(1.0, C1, C2)))
# → True
10Período T₀
Un ciclo del coseno mide 2π: despejamos el tiempo de una vuelta.
\begin{aligned} \omega\cdot T_0=2\pi\;\Rightarrow\;T_0&=\frac{2\pi}{\omega}=\frac{2\pi}{\sqrt{\frac{g}{L}}}=\frac{2\pi}{\frac{\sqrt{g}}{\sqrt{L}}}=2\pi\,\frac{\sqrt{L}}{\sqrt{g}}\\ T_0&=\boxed{2\pi\sqrt{\frac{L}{g}}} \end{aligned}
# el coseno se repite cada 2π
T0 = 2 * math.pi / omega
print(math.isclose(T0, 2*math.pi*math.sqrt(L/g)))
# → True
11Evaluación numérica (L = 1 m, g = 9.81 m/s²)
Con L = 1 m y g = 9.81 m/s² una vuelta dura unos 2 segundos.
T_0=2\pi\sqrt{\frac{1}{9.81}}\approx 2.0061\ \text{s}
print(f"T0 = {T0:.4f} s")
# → T0 = 2.0061 s
# tras un período completo θ vuelve a θ0
print(math.isclose(theta(T0), theta0))
# → True

Punto 3Justificar sen θ ≈ θ con el polinomio de Taylor y estimar el error relativo en θ₀ = 10° y θ₀ = 90°.
# ── PUNTO 3 ────────────────────────────
13Polinomio de Taylor centrado en a
Escribimos una función como una suma de potencias.
\begin{aligned} f(\theta)&=f(a)+f'(a)(\theta-a)\\ &\quad+\frac{f''(a)}{2!}(\theta-a)^{2}+\frac{f'''(a)}{3!}(\theta-a)^{3}+\cdots \end{aligned}
# Σ f⁽ⁿ⁾(a)/n! · (θ − a)ⁿ
def taylor(derivadas, th, centro=0.0):
    # n = 0, 1, 2, ... recorre las derivadas en orden
    return sum(d / math.factorial(n) * (th - centro)**n
               for n, d in enumerate(derivadas))
14Centro a = 0 (Maclaurin)
Centramos en 0 porque el péndulo oscila alrededor de la vertical.
\begin{aligned} f(\theta)&=\frac{f(0)}{0!}\theta^{0}+\frac{f'(0)}{1!}\theta^{1}+\frac{f''(0)}{2!}\theta^{2}+\frac{f'''(0)}{3!}\theta^{3}+\cdots\\ &\qquad (0!=1,\;\;1!=1,\;\;\theta^{0}=1)\\ f(\theta)&=f(0)+f'(0)\,\theta+\frac{f''(0)}{2!}\theta^{2}+\frac{f'''(0)}{3!}\theta^{3}\\ &\quad+\frac{f^{(4)}(0)}{4!}\theta^{4}+\frac{f^{(5)}(0)}{5!}\theta^{5}+\cdots \end{aligned}
# a = 0: la vertical
centro = 0.0
print(math.factorial(0), math.factorial(1))
# → 1 1
15Derivadas de sen θ evaluadas en 0
Las derivadas se repiten cada 4; en 0 valen 0, 1, 0, −1, …
\begin{aligned} f(\theta)&=\sen\theta &&\Rightarrow\; f(0)=\sen 0=0\\ f'(\theta)&=\cos\theta &&\Rightarrow\; f'(0)=\cos 0=1\\ f''(\theta)&=-\sen\theta &&\Rightarrow\; f''(0)=-\sen 0=0\\ f'''(\theta)&=-\cos\theta &&\Rightarrow\; f'''(0)=-\cos 0=-1\\ f^{(4)}(\theta)&=\sen\theta &&\Rightarrow\; f^{(4)}(0)=\sen 0=0\\ f^{(5)}(\theta)&=\cos\theta &&\Rightarrow\; f^{(5)}(0)=\cos 0=1 \end{aligned}
# sen → cos → −sen → −cos y se repite cada 4
ciclo = [math.sin, math.cos,
         lambda x: -math.sin(x), lambda x: -math.cos(x)]
# n % 4 dice en qué parte del ciclo va
derivadas = [ciclo[n % 4](centro) for n in range(6)]
# el + 0.0 es para que no salga -0.0
print([d + 0.0 for d in derivadas])
# → [0.0, 1.0, 0.0, -1.0, 0.0, 1.0]
16Se reemplaza y se simplifican los factoriales
Reemplazamos las derivadas: solo quedan las potencias impares.
\begin{aligned} \sen\theta&=0+(1)\,\theta+\frac{0}{2!}\theta^{2}-\frac{1}{3!}\theta^{3}+\frac{0}{4!}\theta^{4}+\frac{1}{5!}\theta^{5}-\cdots\\ &=0+\theta+0-\frac{\theta^{3}}{3!}+0+\frac{\theta^{5}}{5!}-\cdots\\ &=\theta-\frac{\theta^{3}}{6}+\frac{\theta^{5}}{120}-\cdots \end{aligned}
# cada derivada entre n!
coef = [d / math.factorial(n)
        for n, d in enumerate(derivadas)]
print(math.factorial(3), math.factorial(5))
# → 6 120
print([round(c, 5) + 0.0 for c in coef])
# → [0.0, 1.0, 0.0, -0.16667, 0.0, 0.00833]
17Ángulo pequeño: se desprecian θ³/6 y θ⁵/120
Si θ es pequeño, θ³ y θ⁵ son casi 0: sen θ ≈ θ.
\theta\ \text{pequeño (rad)}:\quad \frac{\theta^{3}}{6}\approx 0,\quad \frac{\theta^{5}}{120}\approx 0\;\;\Rightarrow\;\;\boxed{\sen\theta\approx\theta}
# ángulo pequeño, en radianes
x = math.radians(5)
# solo f(0) y f'(0)·θ
lineal = taylor(derivadas[:2], x)
print(f"sen = {math.sin(x):.5f}  lineal = {lineal:.5f}")
# → sen = 0.08716  lineal = 0.08727
18Error relativo porcentual
Cuánto nos equivocamos al cambiar sen θ por θ, en porcentaje.
\begin{aligned} E_r&=\frac{|\text{valor real}-\text{valor aprox.}|}{|\text{valor real}|}\times 100\%\\ E_r&=\frac{|\sen\theta_0-\theta_0|}{|\sen\theta_0|}\times 100\% \end{aligned}
# |real − aprox| / |real| · 100
def error_relativo(grados):
    # primero a radianes
    th = math.radians(grados)
    return abs(math.sin(th) - th) / abs(math.sin(th)) * 100
19Para θ₀ = 10°
A 10° el error es menor al 1 %: la aproximación sirve.
\begin{aligned} \theta_0&=10^{\circ}\cdot\frac{\pi}{180^{\circ}}\approx 0.17453\ \text{rad}\\ \sen(10^{\circ})&\approx 0.17365\\ E_r&=\frac{|0.17365-0.17453|}{0.17365}\times 100\%\\ &=\frac{0.00088}{0.17365}\times 100\%\approx 0.51\% \end{aligned}
th = math.radians(10)                # 10° · π/180
print(f"{th:.5f} rad   sen = {math.sin(th):.5f}")
# → 0.17453 rad   sen = 0.17365
print(f"{error_relativo(10):.2f} %")
# → 0.51 %
20Para θ₀ = 90°
A 90° el error es de 57 %: ya no sirve.
\begin{aligned} \theta_0&=90^{\circ}\cdot\frac{\pi}{180^{\circ}}=\frac{\pi}{2}\approx 1.57080\ \text{rad}\\ \sen(90^{\circ})&=1.00000\\ E_r&=\frac{|1-1.57080|}{1}\times 100\%\\ &=0.57080\times 100\%=57.08\% \end{aligned}
th = math.radians(90)                # 90° = π/2
print(f"{th:.5f} rad   sen = {math.sin(th):.5f}")
# → 1.57080 rad   sen = 1.00000
print(f"{error_relativo(90):.2f} %")
# → 57.08 %
21Resumen y conclusión
Sirve para ángulos pequeños, no para grandes.
\begin{gathered} \begin{array}{c|c|c|c|c} \theta_0 & \theta_0\ (\text{rad}) & \sen\theta_0 & \theta_0\ (\text{aprox.}) & E_r\\ \hline 10^{\circ} & 0.17453 & 0.17365 & 0.17453 & 0.51\%\\ 90^{\circ} & 1.57080 & 1.00000 & 1.57080 & 57.08\% \end{array}\\[8pt] 10^{\circ}:\ E_r=0.51\%<1\%\;\Rightarrow\;\sen\theta\approx\theta\ \text{válida}\\ \text{para oscilaciones pequeñas}\\[6pt] 90^{\circ}:\ E_r=57.08\%\;\Rightarrow\;\text{deja de ser válida}\\ \text{para ángulos grandes} \end{gathered}
# las dos filas de la tabla
for grados in (10, 90):
    th = math.radians(grados)
    print(f"{grados:>3}°  {th:.5f}  {math.sin(th):.5f}  "
          f"{th:.5f}  {error_relativo(grados):.2f} %")

2. Del papel al código: RK4 y verificación

Un integrador no resuelve una ecuación de segundo orden directamente: primero la partimos en dos ecuaciones de primer orden. Después demostramos que el código coincide con la deducción.

Indicación de la guía. «Ningún integrador numérico resuelve directamente una ecuación de segundo orden: hay que convertirla primero. Con u = θ y v = θ', la ecuación queda: u' = v; v' = −(g/L)·sen u (real); v' = −(g/L)·u (lineal)».

El sistema y el paso RK4

u = θ, v = θ' ⇒ u' = v, v' = −(g/L)·sen u (o −(g/L)·u)
yₙ₊₁ = yₙ + (h/6)·(k₁ + 2k₂ + 2k₃ + k₄)
  1. RK4: cuatro pendientes k₁…k₄ y un promedio ponderado en el que las dos de la mitad pesan el doble.
  2. Verificación 1 (lineal): RK4 aplicado a θ'' + (g/L)θ = 0 se superpone con la solución deducida a mano θ₀·cos(ωt); la diferencia es del orden de 1e-11 rad.
  3. Verificación 2 (real): RK4 coincide con la solución exacta en funciones elípticas de Jacobi; en el panel se ven como una sola curva.
  4. Paso h: al reducirlo diez veces la curva no cambia. Se usan subpasos de ≈ 1.7 ms para animar y 0.5 ms para medir períodos.

Errores evitados: paso h demasiado grande, grados mezclados con radianes, unidades inconsistentes y curvas comparadas en vectores de tiempo distintos.

01De 2º orden a sistema de 1er orden
Partimos la ecuación en dos: una para el ángulo y otra para la velocidad.
\begin{aligned} u=\theta,\quad v&=\theta'\\ u'&=v\\ v'&=-\frac{g}{L}\sen u\quad\text{(real)}\\ v'&=-\frac{g}{L}\,u\quad\ \ \text{(lineal)} \end{aligned}
import math
import numpy as np

g, L = 9.81, 1.0
# ω, la misma del punto 1
w = math.sqrt(g / L)

# y = [u, v] = [θ, θ']
def F_real(t, y):
    u, v = y
    return np.array([v, -(g / L) * np.sin(u)])

# igual, pero sen u ≈ u
def F_lineal(t, y):
    u, v = y
    return np.array([v, -(g / L) * u])
02Un paso de RK4
RK4 avanza con 4 pendientes; las dos del medio cuentan doble.
\begin{aligned} k_1&=F\left(t_n,\;y_n\right)\\ k_2&=F\!\left(t_n+\tfrac{h}{2},\;y_n+\tfrac{h}{2}k_1\right)\\ k_3&=F\!\left(t_n+\tfrac{h}{2},\;y_n+\tfrac{h}{2}k_2\right)\\ k_4&=F\left(t_n+h,\;y_n+h\,k_3\right)\\ y_{n+1}&=y_n+\frac{h}{6}\left(k_1+2k_2+2k_3+k_4\right) \end{aligned}
def rk4(F, y0, t):
    # una fila por instante
    Y = np.zeros((len(t), 2))
    Y[0] = y0
    h = t[1] - t[0]                  # paso fijo
    for i in range(len(t) - 1):
        # al inicio
        k1 = F(t[i], Y[i])
        # a la mitad
        k2 = F(t[i] + h/2, Y[i] + h/2 * k1)
        # a la mitad
        k3 = F(t[i] + h/2, Y[i] + h/2 * k2)
        # al final
        k4 = F(t[i] + h, Y[i] + h * k3)
        # las de la mitad pesan el doble
        Y[i+1] = Y[i] + h/6 * (k1 + 2*k2 + 2*k3 + k4)
    return Y
03Verificación 1 · modelo lineal contra la solución a mano
La simulación y la fórmula hecha a mano casi no se diferencian.
\max_t\left|\,\theta_{\text{RK4}}(t)-\theta_0\cos(\omega t)\,\right|\approx 10^{-11}\ \text{rad}
# el mismo caso de pendulo.py
theta0 = math.radians(45)
t = np.arange(0, 10 + 1e-9, 1e-3)    # h = 0.001 s
Y = rk4(F_lineal, [theta0, 0.0], t)
# la deducida a mano
exacta = theta0 * np.cos(w * t)
# mismo vector t para las dos curvas
print(f"{np.max(np.abs(Y[:, 0] - exacta)):.2e} rad")
# → 1.88e-11 rad
04Verificación 2 · modelo real contra la solución exacta
El período exacto del péndulo real sale de una integral elíptica.
\begin{aligned} T&=\frac{2T_0}{\pi}\,K\!\left(\sen\frac{\theta_0}{2}\right)=\frac{T_0}{\operatorname{AGM}\!\left(1,\ \cos\frac{\theta_0}{2}\right)}\\ \theta_0=90^{\circ}\;\Rightarrow\;T&\approx 2.3678\ \text{s} \end{aligned}
# sale de la integral elíptica
def periodo_exacto(grados):
    T0 = 2 * math.pi / w
    a, b = 1.0, math.cos(math.radians(grados) / 2)
    # media aritmético-geométrica
    while abs(a - b) > 1e-15:
        a, b = (a + b) / 2, math.sqrt(a * b)
    return T0 / a

print(f"T(90°) = {periodo_exacto(90):.4f} s")
# → T(90°) = 2.3678 s

PARTE 3medición del error

3. Medir el período y hallar el umbral

La magnitud que importa no es el ángulo, sino el tiempo. Para medirlo, el péndulo se suelta desde el reposo y se detecta cuándo la velocidad vuelve a cero: ese instante es media oscilación.

Enunciado. «Medir el período real en cada caso (detectar cuándo la velocidad vuelve a cero) y hacer una tabla con el error porcentual frente a T₀. Graficar el error del período en función de θ₀ y determinar a partir de qué ángulo el error supera el 1 %».

01La velocidad vuelve a cero en medio período
Cuando la velocidad vuelve a 0 va por la mitad: el período es el doble.
\theta'(t^{*})=0\ \ \text{en el extremo opuesto}\;\Rightarrow\;T=2\,t^{*}
import math

g, L = 9.81, 1.0
# período lineal, 2.0061 s
T0 = 2 * math.pi * math.sqrt(L / g)

# un paso RK4 del péndulo real
def paso(u, v, h):
    f = lambda u, v: (v, -(g / L) * math.sin(u))
    k1 = f(u, v)
    k2 = f(u + h/2*k1[0], v + h/2*k1[1])
    k3 = f(u + h/2*k2[0], v + h/2*k2[1])
    k4 = f(u + h*k3[0], v + h*k3[1])
    return (u + h/6*(k1[0] + 2*k2[0] + 2*k3[0] + k4[0]),
            v + h/6*(k1[1] + 2*k2[1] + 2*k3[1] + k4[1]))

def periodo_real(grados, h=1e-4):
    # sale del reposo
    u, v, t = math.radians(grados), 0.0, 0.0
    while True:
        v_ant = v
        u, v = paso(u, v, h)
        t += h
        # θ' pasó de − a +: otro extremo
        if v_ant < 0 <= v:
            # se interpola entre los dos pasos para hallar t*
            t_cero = t - h + h * (-v_ant) / (v - v_ant)
            # ese instante es T/2
            return 2 * t_cero

print(f"T(90°) = {periodo_real(90):.4f} s")
# → T(90°) = 2.3678 s
02Error porcentual del período
Cuánto más tarda el real que el lineal, en porcentaje.
\begin{aligned} E&=\frac{T-T_0}{T}\times 100\%\qquad\text{(contra }T\text{, como la guía)}\\ E_{T_0}&=\frac{T-T_0}{T_0}\times 100\% \end{aligned}
# la guía divide entre T real
def error_periodo(grados):
    T = periodo_real(grados)
    return (T - T0) / T * 100

Lectura de la curva de error

  1. El error es monótono: a más amplitud, más demora del péndulo real.
  2. Hasta ≈ 23° el modelo lineal sirve para cronometrar (error ≤ 1 %).
  3. A 45° el error es 3.8 %; a 90°, 15.3 %; a 150°, 43 %. La aproximación ya no es defendible.
  4. El punto donde la curva cruza la línea roja del 1 % es el criterio de diseño.

4. Animación 3D y conclusión

Dos péndulos soltados al mismo tiempo desde 90°: el real y el lineal. El real se atrasa y la diferencia se ve a simple vista.

Pregunta del enunciado. «¿Un reloj de péndulo adelanta o atrasa si se le aumenta la amplitud?»

Qué muestra la simulación

  1. A 90°, los dos salen de θ(0) = 90° con θ'(0) = 0.
  2. En 10 segundos el péndulo lineal (violeta) completa más oscilaciones que el real (dorado).
  3. A 10° las dos pesas se mueven juntas: ahí la aproximación funciona.
  4. L y g se pueden cambiar y todo se recalcula.

Conclusión de ingeniería

Si se acepta como mucho 1 % de error en el período, el ángulo de trabajo debe ser ≤ 23°. Si se necesita precisión de tiempo, se diseña con θ₀ ≤ 10°, donde el error es 0.19 %. Y respondiendo a la pregunta: el reloj atrasa, porque al aumentar la amplitud crece el período real; a 90° pierde unos 220 minutos por día.

Preguntas frecuentes

  1. ¿Por qué T₀ no depende de la amplitud? Porque en θ'' + ω²θ = 0 la frecuencia es ω = √(g/L); la amplitud solo escala la solución.
  2. ¿Cómo saben que el integrador está bien? Porque coincide con la solución exacta deducida a mano y con la solución elíptica del modelo real.
  3. ¿Qué hace el programa y qué no? Verifica y mide; no sustituye la deducción. El error de la aproximación se mide, no se esconde.
  4. ¿Qué pasa si agrandan el paso h? La trayectoria se deforma; al reducirlo diez veces la curva se estabiliza.
