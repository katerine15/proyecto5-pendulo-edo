Guía Resuelta: "Lo que resuelven a mano" y Pregunta de Exposición

Desarrollo paso a paso del Proyecto 5

1. Resolver la ecuación lineal con θ(0) = θ₀, θ'(0) = 0 y deducir T₀ = 2π√(L/g)

Partimos de la EDO linealizada de segundo orden con coeficientes constantes:

θ''(t) + (g/L)·θ(t) = 0 ; definimos ω₀² = g/L ⇒ θ'' + ω₀²·θ = 0

Su ecuación característica es r² + ω₀² = 0 ⇒ r = ±i·ω₀. Por tanto, la solución general es:

θ(t) = C₁·cos(ω₀·t) + C₂·sen(ω₀·t)

Aplicando las condiciones iniciales θ(0) = θ₀ ⇒ C₁ = θ₀, y derivando θ'(t) = -ω₀·C₁·sen(ω₀t) + ω₀·C₂·cos(ω₀t), evaluamos θ'(0) = 0 ⇒ C₂ = 0. Así obtenemos:

θ_lineal(t) = θ₀ · cos( √(g/L) · t )

Como el coseno se repite cada 2π radianes (ω₀·T₀ = 2π), despejamos el período T₀ para L = 1 m y g = 9.81 m/s²:

T₀ = 2π / ω₀ = 2π · √(L/g) = 2π · √(1 / 9.81) ≈ 2.006067 s ≈ 2.0061 s

2. ¿Por qué T₀ no depende de la amplitud θ₀ en el modelo lineal, pero en el real sí?

En la fórmula T₀ = 2π√(L/g) no aparece θ₀ (propiedad de isocronismo de Galileo para oscilaciones pequeñas). Sin embargo, en el péndulo real la fuerza restauradora es proporcional a sen(θ), que es menor que θ cuando el ángulo crece (sen(θ) < θ). Como el péndulo real siente menos fuerza empujándolo de regreso que el modelo lineal, tarda más tiempo en completar cada ciclo:

T_real(θ₀) = T₀ · [ 1 + (1/16)θ₀² + (11/3072)θ₀⁴ + ... ] > T₀

3. Polinomio de Taylor de sen(θ) y error relativo en θ₀ = 10° y θ₀ = 90°

Desarrollando sen(θ) en serie de Taylor/Maclaurin alrededor de θ = 0 (con θ en radianes):

sen(θ) = θ - θ³/3! + θ⁵/5! - ... = θ - θ³/6 + θ⁵/120 - ...

Al aproximar sen(θ) ≈ θ, el primer término descartado (estimación de Taylor del error absoluto) es |R₃(θ)| ≈ θ³/6, por lo que el error relativo aproximado es ≈ θ²/6:

Caso A: θ₀ = 10° = π/18 ≈ 0.174533 rad
• sen(0.174533) = 0.173648
• Error rel. exacto: |0.174533 - 0.173648| / 0.173648 = 0.51%
• Estimación Taylor (θ₀²/6): (0.174533)² / 6 ≈ 0.508%
Caso B: θ₀ = 90° = π/2 ≈ 1.570796 rad
• sen(1.570796) = 1.000000
• Error rel. exacto: |1.570796 - 1.0| / 1.0 = 57.08%
• Estimación Taylor (θ₀²/6): (1.570796)² / 6 ≈ 41.12%

Pregunta de cierre para la exposición: "¿Un reloj de péndulo adelanta o atrasa si se le aumenta la amplitud?"

Respuesta contundente: El reloj de péndulo SE ATRASA.

Justificación física y matemática: Un reloj mecánico está calibrado para que cada oscilación dure exactamente T₀ (por ejemplo, 2.0061 s). Si aumentamos la amplitud θ₀, como sen(θ) < θ, la fuerza restauradora real es más débil que la lineal y el período real aumenta (T_real > T₀; por ejemplo, a 45° tarda 2.0863 s y a 90° tarda 2.3679 s). Como cada "tic-tac" tarda más tiempo en ocurrir, las agujas del reloj avanzan más despacio y el reloj se atrasa.
